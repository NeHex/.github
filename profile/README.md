## 🚀 Overview

**NeHex** is a modern personal blogging platform built with a fully decoupled architecture.

It is designed for developers who want:

* Full control over their content
* High performance backend
* Flexible frontend customization
* Easy deployment & scalability

---

## 🧩 Architecture

```text
Frontend (Vue)
      ↓
Backend API (Rust)
      ↓
PostgreSQL + Redis
```

---

## 🛠️ Tech Stack

| Layer      | Technology |
| ---------- | ---------- |
| Backend    | Rust       |
| Frontend   | Vue.js     |
| Database   | PostgreSQL |
| Cache      | Redis      |
| Deployment | Docker     |
